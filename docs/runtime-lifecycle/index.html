给一份 GameScenario JSON 之后，Runtime 在做什么

从 JSON 进场 → GraphSession / GraphRuntime 状态机 → Overlay 展开与渲染 → 交互提交 / 边路由 / Reaction 副作用 → 下一节点，直到 ended。 对应源码：src/runtime/engine/*、schema/expand-overlay*、editor/shell/GraphPlaySurface。

分层 启动 相位 进节点 Overlay 时钟 / Tick 交互与事件 路由 vs 效果 指令表 全生命周期
2026-07-21 修订：已删除 role / surface、 openInteraction / submitInteraction / awaitInteraction / 独立 snapshot.interaction。全部组件 = renderOverlay → overlayMounts；玩家结果 = 皮肤 emit → emitComponentEvent； 相位仅 idle | playing | ended；超时由皮肤自 emit defaultEvent。

1. 分层：谁管什么

引擎只发指令；Session 合成快照；Player 负责媒体时钟与皮肤渲染。

JSON / Store
GameScenario：graph + ui.overlays + variables/entities + reactions + packs。编辑器用 graphScenarioStore.scn() 合出。
GraphRuntime
纯状态机。读 scenario、推进 phase、展开 overlay children、收组件 emit、选边、施加 effects。输出 RuntimeDirective[]。
GraphSession
apply(directives) → SessionSnapshot（clip / overlayMounts / hud / banner / log）。
PlaySurface / Player
播视频；onTimeUpdate → tick；onEnded → performanceEnd；皮肤 emit(event) → session.emitEvent；HUD/交互均在 overlayMounts 里画。
Component / Skin
ComponentRegistry：inputs + events；SkinRegistry：统一 OverlayProps（parry / kou / choice / hpBar…），无 role/surface。

3. 相位状态机

GraphPhase：idle → playing → ended（无 awaitInteraction）

Phase 转移

stateDiagram-v2
  [*] --> idle: ctor
  idle --> playing: start / enterNode → playClip
  playing --> playing: tick / emitEvent → traverse / enterNode
  playing --> ended: 无自动边 & 栈空 / finishEnd
  ended --> [*]

playing

媒体时钟前进；触发 at / window / spawn；组件挂在 overlayMounts。 若只有事件出口边，则声明式停住等皮肤 emit（含超时自 emit）。

声明式等待

不再切相位挂起。节点无默认自动边、走向靠 event → reactions/边时， advanceAuto 不误跳；超时由皮肤 emit(defaultEvent)。

ended

finishEnd → banner；本局结束。

redirect

scenario state reaction 的 goto 可硬打断当前节点（如 HP≤0），清空 callStack 后跳转。

5. Overlay：JSON 如何变成画面上的层

权威数据：目录在 scenario.ui.overlays，节点只挂 overlayNodes[]。Runtime 展开成 OverlayInstanceChild（id = mountId/childId）。

展开路径

flowchart LR
  O["ui.overlays[id]
Overlay 模板 + children"] --> E["expandOverlayMount"]
  M["node.data.overlayNodes[]
{ overlay, layout?, reactions? }"] --> E
  E --> C["OverlayInstanceChild
component / trigger / window / params / source"]
  C --> R["runElement"]
  R --> RO["emit renderOverlay"]
  RO --> Snap["snapshot.overlayMounts"]
  Snap --> Skin["skins.renderOverlayMount / OverlayProps"]

何时挂上

  • enter 触发（无 window）→ 立刻 runElement
  • at.ms → tick 到点
  • window.startMs..endMs → 窗口内显示，结束 removeOverlay
  • spawn action → 动态叠层 + ttl 回收

何时卸下

  • 下一节点 playClip：Session 整表清空 overlays / interaction
  • window 结束 / spawn ttl → removeOverlay
  • unmount 时再 fire hidden lifecycle reaction

HUD 特例

血条（battleHpBar）走 overlayMounts + OverlayComponent；绘制时用 skinCtx.hud resolve bind→数值。

编辑侧对称

视频轨编辑经 overlay-edit 写回同一套 ui.overlays + overlayNodes，与 runtime 同一 SSOT。

7. 组件事件（emit）与响应

QTE / 选项 / 热点 / 面板：皮肤判定后 emit(eventId) → Session.emitEvent → Runtime.emitComponentEvent。

emitComponentEvent

sequenceDiagram
  participant Skin as Skin（Parry / Kou / Choice…）
  participant UI as PlaySurface
  participant S as GraphSession
  participant RT as GraphRuntime

  Skin->>UI: emit(eventId)
  Note over Skin: 超时亦自 emit(defaultEvent)
  UI->>S: emitEvent(elementId, eventId)
  S->>RT: emitComponentEvent(elementId, eventId)
  RT->>RT: resolveEventReactions(mount.reactions, outcome)
  alt reaction 含 advance
    RT->>RT: traverse → enterNode(next)
  else 无显式 advance
    RT->>RT: selectHandleEdge(outcome) 默认找边
    RT->>RT: traverse → enterNode(next)
  end
  RT-->>S: directives
  S-->>UI: 新 snapshot（overlayMounts）
Event key 优先级： outcome → childId:outcome → mountId:outcome → mountId:childId:outcome （见 overlay-events.ts）。

Reaction 触发面一览

when.type挂在哪何时跑能不能改走向
enter / at / exit节点 data.reactions进节点 / tick / 离节点仅 effect
complete节点advanceAuto 前仅 effect（首个 if 命中）
eventmount overlayNodes[].reactionsemit 出 outcome 后effect + 可选 advance；否则默认找边
shown / hidden节点 / mount组件挂载 / 卸载仅 effect
statescenario.reactions每次 applyAndReact 后 checkRulesgoto → redirect
watchscenario / 节点 / mount写屏障后 pull-diffeffect（可配）

8. 铁律：边 = 路由，Reaction = 效果

Edges（走向）

  • 交互：sourceHandle 对齐 outcome（如 opt:a / pass）
  • 自动：cond:* → else → out；可带 weight RNG
  • 条件：evaluateCondition（var / attr / attrRatio / flag…）

Reactions（效果）

  • do: [{ kind:'effect', effects:[…] }]
  • applyEffects：var / attr / flag / item；值可 {expr}
  • 写后 checkRules + checkWatch
  • 编辑器可从 reaction.goto 派生边，但 runtime 仍只信图上的边

效果写屏障

flowchart LR
  E["effects"] --> A["applyEffects(state)"]
  A --> SC["emit stateChanged"]
  SC --> R["checkRules · state reactions"]
  R -->|goto| RD["redirect 硬跳"]
  R --> W["checkWatch · pull-diff"]
  W --> D["更多 effects / 指令"]

10. 一条完整生命周期（快乐路径）

从 JSON 到 ended

flowchart TD
  J["① 装入 GameScenario JSON"] --> B["② GraphSession + GraphRuntime + initState"]
  B --> S["③ start → enterNode(入口)"]
  S --> P["④ playClip → 播媒体"]
  P --> E["⑤ enter overlays / enter reactions"]
  E --> T["⑥ tick：at / window / spawn · 全部 renderOverlay"]
  T --> W{"⑦ 组件 emit?
或 performanceEnd"}
  W -->|emit| X["emitComponentEvent → reactions / 边"]
  W -->|播完| F["performanceEnd → advanceAuto
（有事件边无默认边则停住）"]
  X --> N["traverse → enterNode(下一节点)"]
  F --> N
  N --> P
  N --> Z["无边 & 栈空 → finishEnd → ended"]
心智模型一句话： JSON 描述图与 overlay 目录；Runtime 按节点时钟展开 children、用 Kind 解析交互、用边走路、用 reaction 改数值； Session 把指令折成快照；Player 只负责播片和画皮肤。
